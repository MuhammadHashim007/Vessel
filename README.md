# 🌌 Haven: Sensory Anchor & Crisis Companion Web App

Haven is a sensory decompression and grounding web application built with **Streamlit** and **HTML5 Canvas / Web Audio**. It is specifically crafted for people undergoing acute anxiety episodes, mental exhaustion, dissociation (the feeling of a blank void), or severe physical stress (racing pulse, high tension).

## ✨ Features
1. **Interactive Fluid Starlight Canvas:** Touch or drag cursor across an obsidian particle canvas with glowing pentatonic chimes that react directly to touch.
2. **Synchronized Breathing Guide:** A breathing aura that guides the user through natural lung decompression (Physiological Sigh) without stressful timers.
3. **Compassionate, Grounded Chat Companion:** A built-in therapeutic companion designed to respond to states of blankness, vascular pressure, and panic with somatic grounding exercises.
4. **Instant Somatic Resets:** One-click evidence-backed techniques (Vagus nerve sigh, Mammalian dive reflex, and Gravity anchoring).
5. **Zero API Keys Required:** Runs 100% locally and deploys seamlessly on Streamlit Community Cloud without external tokens or billing.

## 🚀 Quick Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 🌐 Deploying to Streamlit Cloud via GitHub
1. Create a new GitHub repository named `haven-app`.
2. Push `app.py`, `requirements.txt`, `.gitignore`, and `README.md`.
3. Open [share.streamlit.io](https://share.streamlit.io), connect your GitHub account, choose the repo, and click **Deploy**.
